OpenData Processing Framework

OpenData downloads or reads configured source data, transforms it through registered plugins and loads the resulting data into the configured local database.

Using the graphical interface

• Register adds valid new plugin properties files discovered in the OpenData configuration folder.
• Register from File lets you select a plugin properties file from another location.
• Enable, Disable and Unregister operate on the plugins checked in the Selected column.
• Plugin Detail shows the stored configuration for one checked plugin. Sensitive values are hidden.
• Logs opens the current OpenData application log in a scrollable window.
• Settings shows the effective application configuration without exposing passwords.
• Execute runs the checked enabled plugins in the background and displays the live OpenData log while they run.
• Dry-run executes the checked enabled plugins without provider database writes or generic run-audit rows and displays the same live log window.
• The execution window cannot be closed until processing has completed, after which the Close button becomes available.

Select plugins by checking the Selected box in the main table. The lower-right status reports how many plugins are checked.

Windows compiled Help is being integrated separately. This built-in page remains available as the JavaFX fallback help view.
