This index contains the Version 3.1.0 documentation for the new
`octopus-adjustment` plugin.

The existing OpenData Version 3.0.0 documentation is intentionally unchanged.
This documentation supplements that baseline and applies only to the new plugin
and its related Version 3.1.0 implementation.


## Registration rule

The `octopus-adjustment` plugin is registered through the OpenData **GUI only**.
CLI registration of new plugins is not supported.
