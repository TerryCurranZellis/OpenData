# Glossary

| Term | Meaning |
|---|---|
| ADR | Architecture Decision Record. |
| Dataset | A logical collection of records obtained and processed by a plugin. |
| Manifest | The configuration file that inventories documentation and defines manual composition. |
| Plugin | A component that obtains, transforms and optionally persists one source of data. |
| Source document | A Markdown file used as an input to a generated manual. |
