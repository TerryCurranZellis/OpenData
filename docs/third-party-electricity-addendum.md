# Third-party notices — historical electricity plugin addendum

## Data provider

**National Energy System Operator (NESO)**: source of **Historic Demand Data** and **Historic generation mix and carbon intensity**, retrieved via its CKAN-powered Open Data API. Dataset pages:

- https://www.neso.energy/data-portal/historic-demand-data
- https://www.neso.energy/data-portal/historic-generation-mix

The source portal identifies its data under the **NESO Open Data Licence**. Verify licence terms on each source page for publication and redistribution. Attribute **National Energy System Operator (NESO)** and the original dataset, and retain a reference to the retrieval source and date in downstream documentation. Dataset data are not OpenData-owned software.

## Libraries used directly by both new plugins

- `org.apache.commons:commons-csv:1.14.1` — Apache License 2.0; parsing CSV data.
- `com.fasterxml.jackson.core:jackson-databind:2.22.1` — Apache License 2.0; decoding CKAN JSON responses. Jackson's transitive components retain their own notices.
- `org.junit.jupiter:junit-jupiter` — Eclipse Public License 2.0, test scope only; uses project-managed version.

`java.net.http` and JDBC are Java SE facilities, not additional third-party libraries. No API key or proprietary API client is required. Retain exact dependency notices in release packages generated by Maven.
